# Exact, reviewed denials preserved in raw boot and feature captures.
#
# Format: source -> target : class permission [| key=value ...]
# One permission per record. Qualifiers are literal subsets of property,
# service, interface, path, dev, name, app, ioctlcmd and permissive fields from
# the raw line. They are not regular expressions or cross-product families -- a glob
# character here is matched literally, and until the read -a fix in
# classify-avc-denials.sh it was not (the unquoted `for token in ${required}`
# also ran pathname expansion). A new tuple or a changed required qualifier
# must fail until the exact denial and its mechanism are reviewed.
#
# Matching is SUBSET, in one direction only: every qualifier a rule names must
# be present, and a denial carrying further qualifiers the rule does not name
# still matches. A rule with no qualifier section therefore accepts that tuple
# with any qualifiers at all.
