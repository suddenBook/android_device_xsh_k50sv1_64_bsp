## Scope

The two audit representations in the sanitized runtime log contain 479 AVC
lines. Exact normalization by source context, target context, class,

## Label and domain corrections

* Battery power_supply, LCD backlight, RTC and legacy USB gadget nodes use the
  standard sysfs_batteryinfo, sysfs_leds, sysfs_rtc and sysfs_android_usb
  labels, so existing AOSP HAL/framework rules apply.
* MTK dev_info and /proc/m4u use dedicated read/ioctl types for only the
  audio, camera and media consumers observed at runtime.
* The physical GPT nodes p4, p7 and p29 and their aliases use the standard
  frp_block_device, metadata_block_device and cache_block_device types.
  zram0 uses swap_block_device.
* Twenty live-mapped 32/64-bit MTK graphics SP-HAL objects use
  same_process_hal_file. No framework or app domain receives vendor_file
  execute access.
* Connectivity firmware has its own vendor firmware type read by the kernel;
  the kernel does not receive generic vendor_file access or dac_override.
* Module loading executes vendor insmod in AOSP's vendor_modprobe domain.
  vendor_init does not receive CAP_SYS_MODULE or module_load.
* Root mount points are created by a ramdisk init.mt6755.rc in the platform
  init domain. nvdata, md_cmn and calibration paths retain narrow types.
* The unsupported schedtune hierarchy is removed before zygote. The pinned
  kernel has no schedtune controller, so ordinary tmpfs files are never
  treated as cgroup tasks files.
* HWC gets exact vendor Binder, hotplug uevent and three runtime-property
  contracts. Camera gets only its proven sys_nice, mapper discovery and M4U
  ioctl. Netdagent uses a private PTY instead of generic devpts.
* FILE_VER, device-tree compatibility, modem version, thermal-to-RIL, Wi-Fi
  WMT and Settings zram access are limited to their observed consumers.

## Intentionally denied or quiet fallback

* system_app cannot read /proc/pagetypeinfo.
* system_server cannot access generic block_device.
* apps, zygote and SurfaceFlinger cannot execute generic vendor_file.
* no domain gets generic /proc, generic sysfs, generic device:file or generic
  devpts access for these findings.
* kernel dac_override remains denied by the AOSP neverallow. Tier 2 must prove
  Wi-Fi, Bluetooth and GNSS with firmware mode 0644 and directory mode 0755.
* VSIM, cgroup2 module autoload, the optional fliper probe, ueventd nice reset,
  and Settings APEX/suspend-control probes fail closed and are dontaudited.
