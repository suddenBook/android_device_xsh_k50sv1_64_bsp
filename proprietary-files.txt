#
# Source: immutable factory_image_unpacked filesystem, never the rooted live
# device. Entries are grouped by runtime subsystem and reviewed before use.
#
# Deliberate exclusions:
# - fingerprint feature/HAL/service/app/policy
# - SecPenNote and Stock S Pen popup/sound UI
# - ADUPS FOTA, Facebook, fake Samsung/UMIDIGI identity and product overlays
# - EngineerMode/ATCI/factory test/logging packages unless a measured runtime
#   dependency proves they are required
# - Stock fstab, assembled VINTF, generated/precompiled SELinux policy
#
# A leading '-' packages a Stock library as a preferred prebuilt module. For
# modules that also exist in AOSP, keep every real Stock 32/64 variant so the
# replacement satisfies Soong's complete architecture contract.
